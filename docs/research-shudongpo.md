# 竞品调研：蔬东坡生鲜配送 ERP 功能矩阵

> 版本: 1.0 | 日期: 2026-06-03 | 状态: 已完成

---

## 一、企业概况

蔬东坡（北京木屋时代科技有限公司）成立于 2014 年，是国内**生鲜食材配送垂直 SaaS ERP** 领导者，累计服务 **8000+** 生鲜配送企业，覆盖团膳食堂、餐饮酒店、生鲜连锁、中央厨房等场景。

## 二、产品矩阵

| 产品线 | 目标客户 | 核心定位 |
|--------|---------|---------|
| 生鲜配送系统 | 生鲜配送商 | 进销存 + 配送全链路 |
| 中央厨房系统 | 净菜加工/央厨企业 | 生产加工 + 多业态连锁 |
| 社区团购系统 | 社区团购平台 | 团购 + 营销 |
| S2B2C 系统 | 供应链平台 | 多级分销 + 招商 |
| 生态云平台 | 大型企业 | PaaS 定制 + 业财一体 |

**版本分级**：专业版（基础） → 旗舰版（+询价/食安溯源） → 央厨专版（+加工/计划）

## 三、核心功能详解

### 3.1 订单处理

- **多渠道下单**：PC 后台、微信小程序、H5 商城、电话/语音录入
- **AI 语音下单**：语音识别自动转订单
- **AI 图像识别下单**：拍照识别商品自动生成订单
- **智能定价引擎**：
  - 按客户等级阶梯定价（不同客户看到不同价格）
  - 按区域定价
  - 按采购量阶梯定价
  - 市场行情价自动同步
  - 历史价格记忆
- **报价单管理**：询价 → 报价 → 转订单
- **订单截止时间**：可设定每日截单时间，超时自动锁定
- **订单汇总**：按商品/客户/区域多维度汇总
- **快捷下单**：历史订单一键复制、常购清单快速下单
- **订单变更追踪**：改价/改量/取消全记录

### 3.2 采购管理

- **AI 采购预测**：10+ 维度数据池（历史订单、季节波动、天气、节假日、区域消费特征）
- **阳光采购平台**：供应商在线报价/竞价、多供应商比价
- **采购计划生成**：根据订单汇总 + 库存 + 安全库存自动生成采购建议
- **采购订单管理**：创建、审批、跟踪、入库
- **供应商评估**：交货准时率、品质合格率、价格竞争力评分
- **采购退货**：不合格品退回供应商

### 3.3 分拣称重（核心差异化）

- **智能分拣秤联动**：称重数据自动回传系统
- **按客户分拣**：生成每个客户的分拣任务单
- **按路线分拣**：同路线客户集中分拣
- **扫码分拣**：扫商品条码/二维码
- **实称实重**：鲜活商品按实际重量结算（非标品关键功能）
- **分拣进度追踪**：实时看板

### 3.4 库存管理

- **多仓库管理**：支持多个仓库独立核算
- **冷库温区管理**：冷冻/冷藏/常温分区
- **保质期管理**：生产日期录入、临期预警、FIFO、效期批次追溯
- **非标品库存**：支持重量浮动（实际重量 ≠ 订单重量）
- **盘点管理**：定期盘点、动盘、盲盘
- **库存调拨**：仓库间调拨
- **报损报溢**：损耗记录与分析
- **安全库存预警**：低于安全库存自动提醒采购

### 3.5 配送物流

- **智能排线**：30 分钟排完 2000 家客户路线，支持手动微调
- **司机 APP**：任务查看、签收确认（拍照/签名）、异常上报、客户导航
- **配送状态追踪**：客户可实时查看配送进度
- **签收回单**：电子回单，自动关联订单
- **配送费计算**：按距离/区域/重量自动计算

### 3.6 财务管理

- **应收应付**：客户应收、供应商应付
- **智能对账**：自动匹配订单与收款、差异分析、对账单生成推送
- **账期管理**：月结/周结/现结灵活设置
- **账龄分析**：超期应收预警
- **业财一体**：与金蝶、用友对接
- **利润分析**：按客户/商品/订单的毛利分析
- **成本核算**：采购成本 + 加工成本 + 配送成本
- **发票管理**：开票申请、发票台账

### 3.7 客户管理（CRM）

- **客户分级**：VIP/普通/临时等不同等级
- **客户画像**：消费偏好、下单频率、客单价
- **专属定价**：每个客户可设独立价格表
- **销售员绑定**：客户归属销售管理
- **客户跟进记录**：拜访/电话/微信沟通记录
- **客户账期**：不同客户不同结算周期

### 3.8 中央厨房 / 加工管理

- **菜谱/配方管理**：BOM 物料清单、多级 BOM、营养成分计算、毛利分析
- **生产计划**：根据订单汇总需求、自动生成生产计划、排产排班
- **加工工序管理**：切配/清洗/烹饪/包装、工序报工、产出率管理
- **领料/退料**：按生产计划自动生成领料单
- **成本核算**：原料成本 + 人工成本 + 损耗

### 3.9 食安溯源

- **农残检测记录**：对接检测设备自动记录
- **供应商资质管理**：营业执照、食品许可证等
- **批次追溯**：从原料到成品到客户的正向/反向追溯
- **溯源二维码**：客户扫码查看商品溯源信息

### 3.10 数据分析

- **BI 数据大屏**：实时经营数据可视化
- **多维分析**：销售/客户/商品/采购/库存/配送各维度分析
- **自定义报表**：灵活配置报表维度和指标

### 3.11 移动端

- **客户下单小程序**：微信小程序商城、一键复购
- **司机配送 APP**：任务接收、路线导航、签收拍照
- **管理端 APP**：经营数据看板、审批处理

### 3.12 智能硬件

- 智能分拣秤、农残检测设备、BI 数据大屏、库管 PDA
