# StarOcean 演进路线图 & 实施摘要 (Roadmap)

> ⚠️ **已归档**：早期规划文档，仅作历史参考。M3.5（Goja 插件引擎）与 M4.5（Wasm
> 宿主）方向已放弃——扩展走事件约定（`docs/PLUGINS.md`）；M5 的 SQLite 已从
> “可选”变为默认。**当前事实来源**：`docs/DESIGN.md §0`。

本文档归纳了 **StarOcean** 的核心战略定位、演进路线图里程碑以及具体实施阶段摘要，旨在指导系统未来从极简核心向高扩展性、高一致性的现代化中小型企业（SME）ERP 稳健演进。

---

## 🎯 战略定位与原则

> **以极轻量级架构，提供 70% 功能的 SAP 开源替代方案。**
> 
> 我们剥离了 SAP 中 30% 繁重冗余的设计，精选最能解决企业痛点的 **70% 黄金核心功能**（涵盖销售、采购、仓储、财务及轻量生产），通过单二进制文件提供极致部署体验，并借助**“极简核心 + 插件化扩展（Plugin-based Extensibility）”**实现高度客制化。

*   **DRY & YAGNI**：核心只保留最通用的业务规则，行业特异需求（如服装尺码、危险品追踪、特定折扣）全部由插件承载。
*   **零 CGO 依赖**：坚守单二进制跨平台快速分发的极简体验。
*   **高一致性底座**：核心业务数据流转采用强数据库事务（PostgreSQL Tx），绝不在数据准确性上妥协。

| 里程碑 | 核心目标 | 关键特性 | 验证场景 |
|---|---|---|---|
| **M1: 骨架** | 基础脚手架 | Go 1.26 + Gin + Templ 基础架构，Tailwind CSS 4 暗黑模式，CLI 命令行 | `./starocean serve` 启动并渲染空仪表盘 |
| **M2: 进销存** | 业务主链路闭环 | 商品、客户、供应商 CRUD，销售/采购订单流转，物理出入库流水，库存安全阈值预警 | 单据从草稿到确认，自动锁库/扣减库存，Stock Card 记账 |
| **M3: 财务核销** | 收付款与往来账管理 | 复式核销明细（Allocations），自动/手动拆分分配，欠款账龄分析（Ageing），损益看板 | 收付款多对多分配核销，生成精确账龄报表与现金流预测 |
| **M3.5: 插件引擎** | ~~动态业务扩展~~ **已放弃** | 原计划 Goja 沙箱 + UI 插槽；已降级为事件约定，见 `docs/PLUGINS.md` | — |
| **M4: 生产制造** | 轻量化 PP 模块 | 多级嵌套物料清单（BOM），简易生产工单，自动配料发料（Backflushing），ROP 智能补货建议 | 完成工单流程，自动扣减 BOM 组件库存并增加产成品库存 |

## 📋 实施阶段摘要 (Implementation Phases)

### Phase 2: 财务往来账核销与预测 (Milestone M3)
*   **往来账明细分配**：引入分配表 `reconciliation_allocations`。每笔付款单不再只是一个简单的备注，而是能够清晰记录“核销了哪几张发票的多少金额”。
*   **多发票分配交互**：发票与付款单支持多对多核销。在登记付款时，系统动态抓取未清发票，并支持基于服务端渲染表单的分配交互（支持按最早账期自动分配或手动调整）。
*   **简易损益看板**：聚合销售收入、采购成本以及报销数据（Reimbursements），输出最直观的企业月度损益（Income Statement）与现金流变化趋势。

### Phase 2.5: 插件引擎优化与沙箱治理 (Milestone M3.5) — 已放弃

> 本阶段不再实施。扩展需求走事件约定 + 外部集成（`docs/PLUGINS.md`），
> 不引入脚本引擎与动态 UI 注入。

### Phase 3: PP 生产制造核心功能闭环 (Milestone M4)
*   **嵌套物料清单（BOM）**：支持多级嵌套树形 BOM 结构配置，实现精密物料配比及多单位自动换算。
*   **简易工单与自动领料**：工单下达后进行齐套料检查。支持在完工报工时通过反冲法（Backflushing）自动扣减 BOM 原材料库存，并原子化增加产成品物理库存。
*   **再订货点（ROP）补货引擎**：基于 `现存库存 + 采购在途 - 销售未交 < 安全库存` 简易算法，实时检测物料缺口并一键生成采购申请推荐。

### Phase 3.5: Wazero 嵌入式 WebAssembly 插件宿主 (Milestone M4.5) — 已放弃

> 本阶段不再实施，原因同上。

### Phase 4: 极简分发部署与打印流支持 (Milestone M5)
*   **响应式 Web 打印模板**：在 CSS 中定义极致的 `@media print` 样式模板，过滤页眉、侧边导航等网页元素，提供精美的送货单、对账单与发票的原生浏览器打印。
*   **CGO-free SQLite 可选驱动**：在 PostgreSQL 之外，适配零配置的 `modernc.org/sqlite` 纯 Go 驱动，支持在离线、本地或微型单用户场景下一键启动运行（`./starocean serve --db=sqlite:test.db`）。
